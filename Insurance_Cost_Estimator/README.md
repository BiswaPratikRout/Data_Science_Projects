# Insurance Cost Estimator

A machine learning project that predicts medical insurance charges based on personal and lifestyle factors.

## Features
- Exploratory Data Analysis (EDA) and data visualization
- Machine learning model for estimating insurance charges
- Interactive Streamlit web application
- User inputs include age, BMI, smoking status, number of children, sex, and region

## Technologies Used
- Python, Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- Streamlit, Joblib

## Project Structure
- `insurance_cost_estimator.ipynb` — Data analysis and model development
- `app.py` — Streamlit application
- `insurance_model.pkl` — Trained model
- `model_features.pkl` — Model feature names
- Dataset file — Data used for analysis and training

## Run the Application

Install the dependencies, then run:

```bash
python -m streamlit run app.py
```

## Objective

To explore the factors associated with medical insurance costs and provide estimated charges through an interactive machine learning application.
